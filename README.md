# IPTV-плейлисты

Готовые IPTV-плейлисты в формате M3U для Android, компьютера, Smart TV и телевизионных приставок.

## Плейлисты

| Плейлист | Содержание | Каналов | Ссылка для IPTV-плеера |
|---|---|---:|---|
| **MyTV.m3u** | Русскоязычные, литовские и музыкальные каналы | 1340 | `https://raw.githubusercontent.com/PavelSunStar/IPTV/main/MyTV.m3u` |
| **Russian.m3u** | Русскоязычные каналы | 620 | `https://raw.githubusercontent.com/PavelSunStar/IPTV/main/Russian.m3u` |
| **Lithuanian.m3u** | Литовские каналы | 24 | `https://raw.githubusercontent.com/PavelSunStar/IPTV/main/Lithuanian.m3u` |
| **Music.m3u** | Музыкальные каналы | 743 | `https://raw.githubusercontent.com/PavelSunStar/IPTV/main/Music.m3u` |

Можно скачать нужный файл из репозитория или скопировать прямую ссылку из таблицы в IPTV-плеер.

## Как смотреть на Android

1. Установите IPTV-плеер, например **Televizo**, **OTT Navigator**, **TiviMate** или **VLC**.
2. Выберите добавление нового плейлиста.
3. Выберите загрузку из файла либо вставьте прямую ссылку на нужный плейлист.
4. Дождитесь загрузки списка каналов.

## Как смотреть на компьютере

1. Установите [VLC media player](https://www.videolan.org/vlc/).
2. Откройте **Медиа → Открыть файл** и выберите файл `.m3u`.

Для открытия по ссылке выберите **Медиа → Открыть URL** и вставьте прямую ссылку из таблицы.

## Как смотреть на телевизоре

1. Установите IPTV-приложение, поддерживающее плейлисты M3U.
2. Выберите добавление плейлиста по URL.
3. Введите прямую ссылку на нужный плейлист.
4. Сохраните настройки и обновите список каналов.

Если телевизор не позволяет вводить длинную ссылку, скачайте файл `.m3u` на USB-накопитель и откройте его через приложение, поддерживающее локальные плейлисты.

## Важно

- Репозиторий не хранит и не ретранслирует видеопотоки — здесь находятся только ссылки на общедоступные трансляции.
- Источником списка является открытый проект [IPTV-org](https://github.com/iptv-org/iptv).
- Некоторые каналы могут временно не работать, менять адрес или иметь региональные ограничения.
- Доступность каналов зависит от владельцев трансляций и интернет-провайдера.
- Используйте плейлисты с соблюдением законодательства вашей страны.

## Обновление плейлиста

Если канал перестал работать, сначала обновите плейлист в приложении. При использовании прямой ссылки не нужно заново скачивать файл после каждого изменения в репозитории.
